# TownyElections

Vuoi aggiungere le elezioni al tuo server Minecraft Towny? Allora TownyElections fa per te. TownyElections è completamente open source, e puoi visualizzare e modificare il codice sorgente su [GitHub](https://github.com/vingaming1113/TownyElections).

TownyElections offre:
- Elezioni (ovviamente...)
- Partiti politici
- Multipli sistemi di voto
- Sistema anti-alt
- Supporto PlaceholderAPI
- E molto altro!
