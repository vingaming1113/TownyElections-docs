# Installa TownyElections

Se vuoi scaricare e installare TownyElections, vai prima alla pagina delle release di GitHub collegata di seguito:

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

Scarica il file .jar, **non** il file .zip o .tar.gz.

Ora vai ai file del tuo server, che probabilmente puoi trovare nel pannello del tuo host, poi vai nella cartella plugins e carica il file .jar che hai appena scaricato.

Riavvia o avvia il server. Apparirà una cartella chiamata "TownyElections". Apri la cartella e poi il file `config.yml`.
