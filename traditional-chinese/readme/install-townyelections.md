# 安裝 TownyElections

如果你想下載並安裝 TownyElections，請先前往下方連結的 GitHub Releases 頁面：

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

下載 .jar 檔案，**不要**下載 .zip 或 .tar.gz 檔案。

現在前往你的伺服器檔案，你可以在伺服器主機的控制台中找到伺服器檔案，然後進入 plugins 資料夾，上傳你剛剛下載的 .jar 檔案。

重新啟動或啟動伺服器，將會出現一個名為 "TownyElections" 的資料夾，打開該資料夾，然後編輯 `config.yml` 檔案。
