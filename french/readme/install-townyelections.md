# Installer TownyElections

Si vous souhaitez télécharger et installer TownyElections, rendez-vous d'abord sur la page des versions GitHub liée ci-dessous :

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

Téléchargez le fichier .jar, **pas** le fichier .zip ou .tar.gz.

Accédez maintenant à vos fichiers serveur, que vous pouvez probablement trouver dans le panneau de votre hébergeur, puis allez dans le dossier plugins et téléchargez le fichier .jar que vous venez de télécharger.

Redémarrez ou démarrez le serveur. Un dossier nommé "TownyElections" apparaîtra. Ouvrez le dossier, puis le fichier `config.yml`.
