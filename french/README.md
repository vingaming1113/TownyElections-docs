# TownyElections

Vous souhaitez ajouter des élections à votre serveur Minecraft Towny ? Alors TownyElections est fait pour vous. TownyElections est entièrement open source, et vous pouvez consulter et modifier le code source sur [GitHub](https://github.com/vingaming1113/TownyElections).

TownyElections propose :
- Des élections (bien sûr...)
- Des partis politiques
- Plusieurs systèmes de vote
- Système anti-alt
- Support PlaceholderAPI
- Et bien plus encore !
