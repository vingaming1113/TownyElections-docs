# Install TownyElections

If you want to download and install TownyElections, first go to the github releases page which is linked below<br>

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

Download the jar file, **not** the zip or tar.gz file.



Now go to your server files which you can probably find in your server panel by your server host and then go to the plugins folder and then upload the .jar you just downloaded

restart or start the server, a folder called "TownyElections" will appear, open the folder and then the `config.yml` file.&#x20;
