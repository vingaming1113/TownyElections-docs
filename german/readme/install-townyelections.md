# TownyElections installieren

Wenn Sie TownyElections herunterladen und installieren möchten, besuchen Sie zunächst die GitHub-Releases-Seite, die unten verlinkt ist:

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

Laden Sie die .jar-Datei herunter, **nicht** die .zip- oder .tar.gz-Datei.

Gehen Sie nun zu Ihren Serverdateien, die Sie wahrscheinlich im Bedienfeld Ihres Serverhosts finden, dann in den Ordner plugins und laden Sie die .jar-Datei hoch, die Sie gerade heruntergeladen haben.

Starten Sie den Server neu oder starten Sie ihn. Es erscheint ein Ordner namens "TownyElections". Öffnen Sie den Ordner und dann die Datei `config.yml`.
