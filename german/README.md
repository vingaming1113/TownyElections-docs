# TownyElections

Möchten Sie Wahlen zu Ihrem Minecraft Towny-Server hinzufügen? Dann ist TownyElections genau das Richtige für Sie. TownyElections ist vollständig Open Source, und Sie können den Quellcode auf [GitHub](https://github.com/vingaming1113/TownyElections) einsehen und bearbeiten.

TownyElections bietet:
- Wahlen (natürlich...)
- Politische Parteien
- Mehrere Wahlsysteme
- Anti-Alt-System
- PlaceholderAPI-Unterstützung
- Und vieles mehr!
