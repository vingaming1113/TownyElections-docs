# Установка TownyElections

Если вы хотите скачать и установить TownyElections, сначала перейдите на страницу релизов GitHub, ссылка на которую приведена ниже:

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

Скачайте файл .jar, **не** файл .zip или .tar.gz.

Теперь перейдите в файлы вашего сервера, которые, вероятно, можно найти на панели управления вашего хостинга, затем перейдите в папку plugins и загрузите туда загруженный файл .jar.

Перезапустите или запустите сервер. Появится папка "TownyElections". Откройте папку, а затем файл `config.yml`.
