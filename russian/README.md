# TownyElections

Хотите добавить выборы на ваш сервер Minecraft Towny? Тогда TownyElections — это то, что вам нужно. TownyElections полностью открыт, и вы можете просмотреть и изменить исходный код на [GitHub](https://github.com/vingaming1113/TownyElections).

TownyElections предлагает:
- Выборы (конечно...)
- Политические партии
- Несколько систем голосования
- Система защиты от мультиаккаунтов
- Поддержка PlaceholderAPI
- И многое другое!
