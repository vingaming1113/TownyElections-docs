# TownyElections

Do you want to add elections to your Minecraft Towny server? Then TownyElections is for you. TownyElections is fully open source, and you can view and edit the source code on [GitHub](https://github.com/vingaming1113/TownyElections).\
\
TownyElections adds:\
Elections (of course..)\
Political Parties\
Multiple voting systems\
Anti alt system\
PlaceholderAPI support\
and alot more!
