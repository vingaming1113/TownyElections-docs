# TownyElections

## TownyElections

TownyElections adds formal elections to Towny towns and nations.

Residents nominate themselves, publish campaigns, join parties, and vote. The winner receives your configured Towny ranks, leadership role, or server rewards.

### Key capabilities

* **Town and nation elections** with nomination, voting, and conclusion phases.
* **Plurality, ranked-choice, and approval** voting systems.
* **Political parties** with persistent membership and party standings.
* **Inventory election desk** for candidate details and ballot management.
* **Automatic rewards** for Towny ranks, mayorship, kingship, or commands.

### Requirements

Run Paper `1.21.4+` with Java `21+` and Towny `0.100.0.0+`. Towny `0.103` is recommended.

PlaceholderAPI is optional. It enables TownyElections placeholders for scoreboards and other integrations.
