# Instalar TownyElections

Si deseas descargar e instalar TownyElections, primero ve a la página de lanzamientos de GitHub que se enlaza a continuación:

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

Descarga el archivo .jar, **no** el archivo .zip o .tar.gz.

Ahora ve a los archivos de tu servidor, que probablemente puedas encontrar en el panel de tu servidor de alojamiento, luego ve a la carpeta plugins y sube el archivo .jar que acabas de descargar.

Reinicia o inicia el servidor. Aparecerá una carpeta llamada "TownyElections". Abre la carpeta y luego el archivo `config.yml`.
