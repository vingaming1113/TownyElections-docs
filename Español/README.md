# TownyElections

¿Quieres añadir elecciones a tu servidor Minecraft Towny? Entonces TownyElections es para ti. TownyElections es completamente de código abierto, y puedes ver y editar el código fuente en [GitHub](https://github.com/vingaming1113/TownyElections).

TownyElections ofrece:
- Elecciones (por supuesto...)
- Partidos políticos
- Múltiples sistemas de votación
- Sistema anti-alt
- Soporte para PlaceholderAPI
- ¡Y mucho más!
