# TownyElections

Quer adicionar eleições ao seu servidor Minecraft Towny? Então o TownyElections é para você. O TownyElections é completamente open source, e você pode visualizar e editar o código-fonte no [GitHub](https://github.com/vingaming1113/TownyElections).

O TownyElections oferece:
- Eleições (é claro...)
- Partidos políticos
- Múltiplos sistemas de votação
- Sistema anti-alt
- Suporte ao PlaceholderAPI
- E muito mais!
