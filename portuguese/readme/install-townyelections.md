# Instalar o TownyElections

Se você deseja baixar e instalar o TownyElections, primeiro acesse a página de lançamentos do GitHub vinculada abaixo:

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

Baixe o arquivo .jar, **não** o arquivo .zip ou .tar.gz.

Agora acesse os arquivos do seu servidor, que você provavelmente pode encontrar no painel do seu provedor, depois vá para a pasta plugins e faça o upload do arquivo .jar que você acabou de baixar.

Reinicie ou inicie o servidor. Uma pasta chamada "TownyElections" aparecerá. Abra a pasta e depois o arquivo `config.yml`.
