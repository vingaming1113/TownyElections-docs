# TownyElections

Vil du tilføje valgsystemer til din Minecraft Towny-server? Så er TownyElections noget for dig. TownyElections er fuldstændig open source, og du kan se og redigere kildekoden på [GitHub](https://github.com/vingaming1113/TownyElections).

TownyElections tilbyder:
- Valgsystemer (selvfølgelig...)
- Politiske partier
- Forskellige afstemningssystemer
- Anti-alt-system
- PlaceholderAPI støtte
- Og meget mere!
