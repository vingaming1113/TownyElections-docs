# Installer TownyElections

Hvis du ønsker at downloade og installere TownyElections, skal du først gå til GitHub-releases-siden, som er linket nedenfor:

{% embed url="https://github.com/vingaming1113/TownyElections/releases/latest" %}

Download .jar-filen, **ikke** .zip- eller .tar.gz-filen.

Gå nu til dine serverfiler, som du sandsynligvis kan finde i dit serverpanel hos din serverudbyder, og gå derefter til plugins-mappen og upload den .jar-fil, du netop har downloadet.

Genstart eller start serveren. Der vil fremkomme en mappe kaldet "TownyElections". Åbn mappen og derefter `config.yml`-filen.
